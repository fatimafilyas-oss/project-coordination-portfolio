This section contains coordination checklists related to project setup, task follow-ups, deadlines, communication, handovers, and final review.

- Task follow-up checklists
- Deadline tracking checklists
- Communication checklists

- Final review checklists

## Common Coordination Checklist Structure

| Checklist Area | Purpose |
|---|---|
| Project Setup | Ensures all project details are clear before work begins |
| Task Assignment | Confirms tasks, responsibilities, and deadlines |
| Communication | Tracks updates, reminders, and follow-ups |
| Progress Review | Checks completed, pending, and delayed tasks |
| Final Review | Ensures work is complete before submission or delivery |
