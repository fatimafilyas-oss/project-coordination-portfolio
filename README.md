## Project Coordination Process

For project coordination tasks, I follow this process:

```text
1. Understand the project goal and expected deliverables
2. Break the project into smaller tasks
3. Assign priorities and deadlines
4. Organise tasks using project management tools
5. Track progress and identify pending items
6. Communicate updates clearly
7. Prepare final summaries and documentation
