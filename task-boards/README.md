# Task Boards

This section contains task board structures and examples related to project coordination, workflow tracking, and team task management.

## Purpose

The purpose of this section is to show my ability to organise work into clear stages, track task progress, manage priorities, and support smooth project execution.

## What This Section Will Include

- Trello-style task board examples
- Asana-style workflow structures
- To-do, in-progress, and completed task formats
- Priority-based task boards
- Deadline tracking boards
- Team responsibility boards
- Project status boards
- Follow-up tracking systems

## Common Task Board Structure

| Stage | Purpose |
|---|---|
| To Do | Tasks that need to be started |
| In Progress | Tasks currently being worked on |
| Under Review | Tasks waiting for checking or approval |
| Completed | Finished tasks |
| Follow-Up | Tasks that need further action |
